# Bing Liu's academic homepage

A lightweight, responsive static homepage in English.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000 in your browser.

## Edit

- `index.html`: biography, research interests, publications, and experience.
- `stylesheet.css`: typography, spacing, and mobile layout.

Content is based on Bing Liu's supplied CV. Publication coauthor lists, a profile
photo, and a downloadable CV can be added later. The original template's data,
images, and project directories remain available but are not used by the homepage.
The inherited `jonbarron.info` custom domain has been removed.

The repository originally used Jon Barron's academic website template
(https://jonbarron.info/). The current homepage has been rewritten with a simple
text-focused layout, inspired by https://zhiyuzz.github.io/.
